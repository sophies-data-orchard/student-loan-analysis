# Student Loan Analysis

This repository contains **my individual contribution** to a graduate-level team project analyzing U.S. student loan data.

My work focused on data preparation, exploratory data analysis (EDA), feature engineering, and regression modeling to investigate factors associated with student loan balances. The analyses, code, and interpretations included here represent my own work rather than the complete team deliverable.

---

## Project Context

The broader course project examined U.S. student loan data using statistical analysis to better understand borrowing patterns and the factors associated with student loan balances.

Within the project, I was responsible for:

- Data preparation and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- Regression modeling
- Interpretation of statistical results

This repository documents my analytical workflow and contributions.

---

## Analysis Workflow

| Step | Description |
|------|-------------|
| Data Preparation | Cleaned and transformed the source data for analysis |
| Exploratory Data Analysis | Examined variable distributions, relationships, and data quality |
| Feature Engineering | Prepared variables for statistical modeling |
| Regression Modeling | Built regression models to evaluate factors associated with student loan balances |
| Interpretation | Analyzed model results and discussed findings and limitations |
